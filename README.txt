SNAKE GAME - WORKING VERSION

Files:
- index.html
- style.css
- script.js
- background.wav  -> background music
- explosion.wav   -> wall/self collision sound

IMPORTANT:
1. Keep all files in the SAME folder.
2. If you already have back.jpg, put it in this folder. The game will use it automatically.
3. The game starts after pressing PLAY.
4. Background music starts from the PLAY button (browser autoplay-safe).
5. Explosion plays on wall collision and self collision.
6. On mobile, swipe the canvas. No on-screen controls are shown.
7. For local testing, VS Code Live Server is recommended.

Do NOT rename background.wav or explosion.wav unless you also change the names in index.html.
